CSS introduction

Cascading Styling Sheets

It is used for adding styles to the web page.

And also used to create Responsive Web Design.

We use 3rd version

Father of CSS: Hackon Wium Lie and Bert Bose

We use property and values in CSS.

To insert CSS in HTML there are three ways: Inline Styling , Internal Styling , External Styling.

Inline Styling means we use style attribute with in the tag and syntax is style="property:value"

Internal Styling means we use style tag with in head section and syntax is open style tag then selector{ property:value} then close style tag

External Styling means we create seperate files for css stylings with .css extensions.

So we can access the style attribute in 3 ways based on the order of priority that is inline > internal > External

If we use !important it will also display the colors based on the order of priority.
